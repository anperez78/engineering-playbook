---
name: review-code
description: Review a change for correctness, design, testing, security and operational readiness.
---
1. Read the diff and requirements/OpenSpec artifacts.
2. Review correctness and regression risks.
3. Review security-sensitive paths and risk-based test coverage.
4. Check quality-gate results; verify claims against actual output.
5. Report findings by severity with locations and concrete fixes. Do not edit code unless asked to remediate.
