---
name: implement-feature
description: Implement an agreed feature or OpenSpec change with focused tests and quality checks.
---
1. Read project instructions and approved OpenSpec artifacts.
2. Implement the smallest coherent change; do not silently expand scope.
3. Add unit tests for domain invariants and use cases.
4. Add integration/contract/E2E tests when boundaries or critical journeys are affected.
5. Run formatting, lint, type checks and relevant tests; report anything not run.
6. Consult code/security reviewers when relevant.
7. Summarize files, behavior, tests, migration/operational concerns and limitations.
